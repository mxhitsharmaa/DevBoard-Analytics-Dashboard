# DevBoard — Analytics Dashboard

A developer-focused analytics dashboard built with React, TypeScript, Tailwind CSS, Recharts, and Vite.

DevBoard provides a clean interface for viewing analytics, tracking activity, and understanding project performance through charts, summary cards, and searchable tables.

## Features

- Responsive dashboard layout for desktop, tablet, and mobile.
- Summary cards for key metrics.
- Charts and visual data summaries using Recharts.
- Searchable recent orders table.
- Sidebar navigation.
- Clean, modern dashboard interface.
- React and TypeScript for reusable, maintainable components.

## Tech Stack

- React
- TypeScript
- Tailwind CSS
- Recharts
- Lucide React
- Vite

## Getting Started

### Prerequisites

Install Node.js and npm.

### Installation

```bash
git clone https://github.com/mxhitsharmaa/DevBoard-Analytics-Dashboard.git
cd DevBoard-Analytics-Dashboard
npm install
npm run dev
```

Open the local URL shown in your terminal.

## Production Build

```bash
npm run build
npm run preview
```

## What Makes DevBoard Different?

DevBoard focuses on presenting important project information in a single, easy-to-understand interface. Its reusable React components, typed code, responsive layout, and visual charts make the project useful both as a dashboard and as a frontend development learning project.
